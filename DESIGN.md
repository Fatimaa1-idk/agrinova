# Agrinova Design System

## Color Strategy
**Committed**: Vert agricole comme couleur principale (30-60% de l'interface)

### Palette OKLCH
- **Primary (Terre)**: oklch(0.32 0.18 142) - Vert profond, terneux
- **Secondary (Or)**: oklch(0.78 0.15 65) - Or doux, récolte
- **Surface (Terre cuite)**: oklch(0.96 0.02 42) - Beige chaud, naturel
- **Neutral (Sable)**: oklch(0.92 0.01 42) - Neutre teinté

### Semantic Colors
- **Success**: oklch(0.65 0.16 142) - Récolte réussie
- **Warning**: oklch(0.78 0.15 65) - Attention naturelle
- **Error**: oklch(0.55 0.18 25) - Sécheresse, urgence

## Theme
**Light** - Producteurs travaillent en plein soleil, besoin de lisibilité. Interface claire comme un champ ensoleillé.

## Typography
- **Primary**: Inter (lisible, accessible)
- **Display**: Manrope (élégant mais pas technologique)
- **Scale**: 14px → 18px → 24px → 32px (ratio 1.3)
- **Line length**: Max 68ch (respect de la lecture mobile)

## Layout
- **Rhythm**: Espacement variable (8px, 12px, 20px, 32px)
- **Cards**: Usage minimal, seulement quand nécessaire
- **Containers**: Pas de wrapping excessif
- **Grid**: Agricole (2-3-4 colonnes, comme des rangées)

## Motion
- **Curve**: ease-out-quart (naturel comme une plante qui pousse)
- **Duration**: 200ms (rapide mais perceptible)
- **No layout animations**: Jamais d'animation sur les propriétés de layout

## Component Philosophy
- **Forms**: Simples, directs, pas d'étapes inutiles
- **Navigation**: Bottom-first (mobile), claire et constante
- **Feedback**: Immédiat, visuel, pas de modales par défaut
- **Data**: Présenté pour les producteurs, pas pour les analystes
